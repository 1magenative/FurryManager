# FurryManager — контекст проекта для разработки

> Этот файл — точка входа для новой сессии разработки (человека или ИИ).
> **Обновлять при каждом значимом изменении программы.**
> Последнее обновление: 2026-07-26, версия **v0.6.0** (стабильное состояние;
> v0.5.0 выпущена ранее). Поддерживаются **Windows и Linux (Ubuntu 22.04+)**.

## Что это

Локальный менеджер фурри-артов для Windows и Linux: теги вместо папок, коллекции,
группы (комиксы и вариации), дедупликация, ИИ-поиск по описанию, автотеги,
скачивание с e621/FurAffinity через браузерное расширение, мобильный доступ
через PWA. Всё хранится и работает локально.

Пользователь и владелец проекта — Michael (не подтверждал глубокий опыт
программирования; собирает и тестирует сам по инструкциям, ошибки сборки
присылает текстом). Язык общения — русский. UI — на русском.

## Стек и структура

| Часть | Технология | Папка |
|---|---|---|
| Десктоп-приложение | Tauri 2 (Rust, MSVC) | `src-tauri/` |
| Фронтенд | Vanilla JS/HTML/CSS, **без Node и сборщика** (`withGlobalTauri`) | `ui/` |
| Мобильный клиент | PWA, вшита в бинарник через `include_str!` | `src-tauri/pwa/` |
| БД | SQLite (rusqlite, bundled), WAL | `library.db` в папке библиотеки |
| ML-сайдкар | Python 3.11+, JSON-RPC по stdin/stdout | `sidecar/main.py` |
| Расширение браузера | Chrome MV3 | `extension/` |
| Установщик | NSIS (Tauri), хуки деинсталлятора | `src-tauri/windows/hooks.nsh` |
| Документация | ARCHITECTURE.md (дизайн), SETUP.md (установка), RELEASE.md (сборка релиза), этот файл |

Лицензия — MIT (`LICENSE`).

Ключевое ограничение: **Node.js в проекте не используется принципиально** —
у пользователя его нет, фронтенд правится без пересборки (нужен перезапуск
`cargo tauri dev`). У Michael **нет ffmpeg в PATH** — везде нужны фолбэки
(превью и кадры видео снимает фронтенд через WebView).

## Как собирать/запускать

```powershell
cd D:\FurryManager
cargo tauri dev          # dev-запуск
cargo tauri build        # установщик NSIS в src-tauri/target/release/bundle/
```

Требуется: Rust MSVC-тулчейн (НЕ GNU), VS Build Tools, WebView2.
Python-зависимости ИИ: `python -m pip install -r sidecar\requirements.txt`
или из приложения (🧠 → «Установить ИИ-компоненты»).

Релиз целиком (сайдкар + установщик) — `release.ps1`, подробности в
RELEASE.md. Сборка в GitHub Actions (`.github/workflows/release.yml`) идёт
**без** ИИ-сайдкара: PyInstaller + onnxruntime дают ~500 МБ и час сборки.
CI — это проверка «компилируется на чистой машине», раздавать людям нужно
установщик из `release.ps1`.

## Архитектура

### Rust (src-tauri/src/)

- `main.rs` — регистрация ~60 команд, AppState (Mutex<Connection> + root),
  AiState, WatchState, HTTP-сервер, детектор блокировки экрана (Windows:
  опрос GetForegroundWindow → событие `screen-locked`).
- `db.rs` — схема + миграции (ALTER с игнором ошибок). Таблицы: files,
  sources, tags, file_tags, tag_relations, collections, collection_files,
  groups, clip_vectors, deleted_hashes, meta.
- `commands.rs` — все команды (файл большой, ~2600 строк). Важное:
  `build_filters()` — общий парсер поиска; `build_files_where()` — общий
  WHERE для галереи и счётчика; `CARD_COLS` — 13 колонок, групповые в конце
  (доп. колонки конкретных запросов начинаются с индекса 13!);
  `GROUP_COVER_WHERE` — схлопывание групп в стопку; `AI_PENDING_WHERE` —
  что считать непроиндексированным.
- `import.rs` — импорт: SHA-256 → дедуп → копия в `store/xx/hash.ext`
  (или in-place) → превью → dHash. HEIC/AVIF и lossless PNG→WebP.
- `sidecar.rs` — спавн Python, JSON-RPC, Mutex сериализует вызовы.
- `similar.rs` — похожие (CLIP-вектор, фолбэк dHash) + Fluffle.xyz.
- `server.rs` — tiny_http: `/ingest`, `/ingest-file`, `/ping`, статика PWA,
  read-API (`/api/files`, `/api/group`, `/api/collections`, `/api/config`,
  `/thumb/:id`, `/media/:id` с Range).
- `watcher.rs` — notify: слежение за папками, дебаунс, `wait_stable`.
- `heic.rs` — конвертация HEIC/AVIF → JPEG через Python + pillow-heif.

### Python-сайдкар (sidecar/main.py)

Методы: ping, warmup, embed_images / embed_text (fastembed, CLIP ViT-B-32),
tag_images (WD14 swinv2-v3 ONNX, e621-категории), download (gallery-dl,
поддержка `--cookies-from-browser`). После первой загрузки моделей ставится
маркер и включается `HF_HUB_OFFLINE=1`. `LOAD_TRUNCATED_IMAGES=True`.

### Фронтенд (ui/) — ~2600 строк

Галерея с бесконечной прокруткой, просмотрщик (зум/пипетка), стопки групп,
мультивыбор, контекст-меню с подменю (flyout), модалки: настройки (вкладки),
дубликаты, автосбор групп, редактор группы, автораспределение, здоровье,
переиндексация, гайд, справка, шторка приватности.

## Реализовано (история версий)

- **v0.1–0.3.1** — импорт/дедуп/галерея/теги/поиск/похожие, ИИ-сайдкар
  (CLIP + WD14), расширение + gallery-dl, NSFW-вкладки, онбординг.
- **v0.4** (закрыта) — near-dupe «Дубликаты», tag implies/aliases, in-place
  импорт, watcher папок, lossless PNG→WebP.
- **v0.5.0** (выпущена 2026-07-20):
  - **Группы**: комиксы и вариации, стопки в галерее (слои + имя),
    редактор (порядок/тип/имя/роспуск), автосбор (по title и phash),
    имя комикса с e621 (md5 → pool), объединение групп, добавление в группу.
  - **Мобильное**: PWA-галерея (свайпы «как в Фото», pinch-zoom, плёнка
    миниатюр, открытие/закрытие в ячейку), загрузка с телефона, `/ingest`
    по ссылке, QR с токеном, LAN-режим.
  - **iPhone**: HEIC/AVIF-импорт, определение формата по содержимому.
  - **Приватность**: ПИН при запуске + код восстановления + отложенный
    сброс (24 ч), шторка при сворачивании/Win+L, мгновенная блокировка
    (🔒 / Ctrl+L).
  - **Данные**: экспорт/импорт библиотеки в zip, автораспределение по
    коллекциям, полная переиндексация, мультикадровая индексация видео,
    история просмотров, статистика и здоровье библиотеки.
  - **Теги**: массовое редактирование — переименовать / слить / удалить тег
    во всей библиотеке (⚙ Настройки → Теги).
  - **Автономность**: сайдкар упакован PyInstaller'ом (`sidecar/build.ps1`),
    вкладывается в установщик — Python у пользователя не нужен; офлайн-кэш
    выбранных коллекций в PWA на IndexedDB.
  - **Дистрибуция**: NSIS-установщик (per-user, без прав администратора),
    обновление поверх с сохранением настроек и библиотеки, единственное окно
    при повторном запуске, восстановление при пропавшей папке библиотеки,
    версия в ⚙ Настройки → Справка.
  - **Мелочи**: `type:group/comic/variants`, `untagged`, `uncollected`,
    счётчик текущего вида, куки браузера для gallery-dl.

## Известные проблемы и нюансы

- Код пишется без локальной компиляции — Michael собирает и присылает
  ошибки. Частые грабли: E0597 (`query_map().collect()` в хвосте блока →
  `let v = …; v`), забытые `use` трейтов (`Manager`, `Emitter`).
- **bash-песочница ИИ показывает устаревшие/обрезанные файлы** — проверять
  через Read, JS-синтаксис валидировать копией в outputs.
- PWA кэшируется намертво → страница отдаётся с `Cache-Control: no-store`;
  иконку PWA обновляет только переустановка ярлыка.
- Service Worker в PWA по LAN-http невозможен (не secure context) — офлайн-кэш
  артов сделан на IndexedDB. Но при доступе через **Tailscale** (доверенный
  https на `<device>.<tailnet>.ts.net`) SW включается и даёт офлайн-запуск
  оболочки: `pwa/sw.js`, маршрут `/sw.js`, `registerSW()` только при https;
  `tailscale serve` поднимается из настроек командами `ts_serve_enable/…`.
  Самоподписанный https отвергли: tiny_http ssl-rustls → ring 0.16 → Perl+NASM
  в сборке, плюс возня с доверием сертификата на iPhone.
- Умный поиск возвращает top-100 без пагинации.
- Шифрование файлов store не делаем — обсудили и отказались (риск потери
  библиотеки выше выигрыша; защита — шторка с ПИН).
- **PowerShell-скрипты только ASCII**: PS 5.1 читает `.ps1` без BOM как ANSI,
  кириллица ломает парсер. То же правило для `.nsh`.
- **Разрешения Tauri 2**: любой вызов плагина требует записи в
  `capabilities/default.json` (например, «Показать» не работала без
  `opener:allow-open-path`). Не глушить ошибки `.catch(() => {})` — иначе
  отказ разрешения выглядит как «кнопка ничего не делает».
- **`sidecar/dist/PLACEHOLDER.txt` не удалять**: сборка сайдкара в git не
  хранится, но папка должна существовать, иначе build-скрипт Tauri падает
  с `resource path ..\sidecar\dist doesn't exist` (ломало CI).

## Кросс-платформенность (v0.6)

Портировано на Linux; вся платформенная специфика — за `cfg`-флагами:

| Место | Windows | Linux |
|---|---|---|
| Python по умолчанию | `python` | `python3` (`default_python()`) |
| pip | как есть | при PEP 668 повтор с `--break-system-packages` |
| Скрытие папок библиотеки | атрибуты HIDDEN/NOT_CONTENT_INDEXED | файлы `.hidden` + `.nomedia` |
| Консоль дочерних процессов | `CREATE_NO_WINDOW` | не требуется |
| Событие блокировки экрана (Win+L) | `GetForegroundWindow` | нет (шторка по сворачиванию работает) |
| Tailscale | путь в Program Files, запуск через UAC | из PATH, нужен `tailscale set --operator=$USER` |
| Кадры видео | ffmpeg обычно отсутствует → снимает WebView | ffmpeg из репозитория → извлекает бэкенд |
| Пакеты | NSIS `-setup.exe` | `.deb` и AppImage (`targets: "all"`) |
| Сборка | `release.ps1`, `sidecar/build.ps1` | `release.sh`, `sidecar/build.sh` |

Подводные камни Linux: WebKitGTK без gstreamer-кодеков не играет MP4;
вставка картинки из буфера под Wayland может не работать; кросс-сборка из
Windows невозможна — только на Linux (WSL2/VM/CI).

## Дистрибуция

- Установщик per-user в `%LOCALAPPDATA%\FurryManager`, без администратора.
- Настройки: `%APPDATA%\FurryManager\config.json` (путь к библиотеке, ПИН,
  токен сервера). Библиотека — в выбранной пользователем папке.
- Удаление сносит только программу. Галочка «Удалить данные приложения»
  чистит конфиг через хук `src-tauri/windows/hooks.nsh` (штатный
  деинсталлятор Tauri знает только `%APPDATA%\<идентификатор>`).
  **Библиотека не удаляется ни при каком сценарии.** Таблица — в RELEASE.md.
- Установщик не подписан → SmartScreen предупреждает. Лечится только
  покупкой сертификата подписи кода.
