Привет! Я FurryManager

Помогу навести порядок в коллекции артов: теги и коллекции вместо папок, поиск, дубликаты, превью.

🔒 Всё локально. Твои арты и теги хранятся и обрабатываются только на этом компьютере и никуда не отправляются. Интернет — лишь по твоей команде (скачать по ссылке из расширения, найти источник). Никакого облака, аккаунтов и аналитики.

Где хранить библиотеку?

Выбери (или создай) папку — туда я сложу файлы, превью и базу тегов.

Важно понимать: при импорте я копирую файлы в библиотеку. Оригиналы остаются где были — их можно потом удалять, копия в библиотеке сохранится.

Расширение браузера

Сохраняет арты с e621, FurAffinity и др. одним кликом. Установка: Chrome → Расширения → «Режим разработчика» → «Загрузить распакованное» → выбери папку extension из папки проекта. Затем вставь этот токен в настройки расширения:

Куки браузера (возрастной контент)
FurAffinity и e621 отдают взрослый контент только залогиненным. Скачивание возьмёт куки твоей сессии из выбранного браузера — качается ровно то, что видишь сам. Куки читаются локально и никуда не отправляются; браузер при этом лучше закрыть (он держит файл куки заблокированным).
Загрузка из Telegram

Отдельный бот-загрузчик: пересылаешь ему фото, видео или гиф (в том числе пересланные из каналов) — и они попадают в библиотеку. Текст игнорируется. Заведи бота у @BotFather, скопируй токен и вставь сюда. Присланное подхватывается, пока приложение запущено (и при следующем запуске — что скопилось за ~сутки). Большие видео (>20 МБ) Telegram боту не отдаёт.

Доступ с телефона
Отсканируй QR камерой телефона — откроется мобильная страница библиотеки (галерея, поиск, загрузка артов). Там же «Поделиться → На экран Домой» превратит её в приложение. После включения или выключения галочки перезапусти приложение.
Офлайн-галерея на телефоне (Tailscale)

Чтобы мобильная галерея открывалась даже без сети (и работала вне дома), нужен доверенный HTTPS. Его бесплатно даёт Tailscale: поставь его на этот ПК и на телефон, войди в один аккаунт — и нажми кнопку. При первом включении Windows покажет запрос прав администратора — нажми «Да» (иначе Tailscale не даёт настроить доступ). Появятся адрес и QR: открой на телефоне и «Поделиться → На экран Домой». После первого захода приложение запомнит арты (скачиваются кнопкой ⤓ в галерее) и будет открываться офлайн.

Открой этот адрес на телефоне (или отсканируй QR) → «Поделиться → На экран Домой». Дальше галерея открывается офлайн. Если Tailscale не установлен — скачай его с tailscale.com/download на ПК и из App Store на iPhone, войди в один аккаунт и нажми кнопку снова. Если телефон не подключается к адресу — в админке Tailscale включи HTTPS-сертификаты (login.tailscale.com → DNS → «HTTPS Certificates»).

Как пользоваться

🔒 Приватность. Всё работает локально на твоём ПК. Арты и теги никуда не отправляются — ни в облако, ни на серверы, никакой аналитики и аккаунтов. Интернет используется только по твоей команде: скачивание по ссылке из расширения и поиск источника/похожего (кнопки «🔎 Найти источник» и «🏷 Похожее по тегам»). ИИ-модели работают офлайн (скачиваются один раз).

Как это устроено. Библиотека — отдельная папка, куда я копирую каждый импортированный файл. Поэтому: удалил оригинал с рабочего стола — копия в библиотеке осталась; удалил арт в менеджере («🗑 Удалить») — исчезла только копия из библиотеки, оригинал (если он ещё есть) не трогается. Точные дубликаты определяются по содержимому и не занимают место повторно.

Импорт. Кнопка «Импорт» (папка целиком или отдельные файлы) — или просто перетащи файлы/папки прямо в окно. По умолчанию файлы копируются в библиотеку. Фото iPhone в формате HEIC при импорте автоматически конвертируются в JPEG (нужен Python с пакетом pillow-heif — ставится через 🧠 → «Установить ИИ-компоненты»; оригиналы не меняются). Вариант «📎 Папку без копирования» (in-place) оставляет оригиналы на месте — в библиотеку попадают только ссылка, теги и превью; это экономит место, но если ты потом переместишь или удалишь исходный файл, арт в галерее перестанет открываться. Удаление in-place-арта из библиотеки убирает только запись — сам файл на диске остаётся.

Автодобавление из папок. В ⚙ Настройках → «Автодобавление из папок» можно указать папки, за которыми я слежу: новые файлы там сами попадают в библиотеку (можно выбрать режим «без копирования»). Файлы, добавленные при выключенном приложении, подхватываются при следующем запуске. Удалённые из библиотеки арты «запоминаются» и обратно из отслеживаемых папок не возвращаются; вернуть такой арт можно обычным ручным импортом.

Выделение и ПКМ. Ctrl+клик — выбрать несколько артов (Shift+клик — диапазон), Ctrl+Shift+A — выделить все загруженные арты текущего вида (например, всю вкладку SFW; долистай вниз, чтобы охватить всё). Внизу появится панель действий: тег всем, в коллекцию, 🪄 авто-распределение, SFW/NSFW/♻ авто, удалить. Правый клик по арту — быстрое меню.

Поиск. Просто пиши слова: лис куртка — найду по тегам, автору и названию. Тип файла: добавь слово gif, видео или фото (или type:gif) — например gif furry male. Группы: группы или type:group — только стопки; type:comic — комиксы, type:variants — вариации. Здоровье: untagged — без тегов, uncollected — без коллекций. Чип «🕘 Недавние» показывает историю просмотров (свежие сверху), а кнопка 📊 вверху — статистику библиотеки. В умном поиске (🧠) кнопка «только точные» скрывает слабые совпадения.

Рассмотреть арт. В просмотрщике: колесо мыши — зум, перетаскивание — панорама, двойной клик — сброс. ПКМ по арту — зум и 🎨 пипетка: клик по любой точке покажет цвет (HEX сразу копируется в буфер).

Синтаксис (про-режим): раса:лис — тег в неймспейсе; -эскиз — исключить тег; всё комбинируется: раса:лис -эскиз куртка.

Теги и коллекции. Открой арт → справа теги и коллекции. Коллекция — как альбом или плейлист: один арт может быть в нескольких сразу, места это не занимает. Клик по тегу — поиск по нему. В панели под поиском: слева от разделителя — фильтры (Все, SFW/NSFW), справа — твои коллекции (клик — фильтровать галерею), «＋ Новая» — создать. Порядок коллекций, переименование и удаление — в ⚙ Настройках. Фильтр «📥 Без коллекции» показывает нераспределённые арты. Ещё можно вставить арт из буфера обмена: ПКМ по пустому месту галереи — «Вставить из буфера» (арт попадёт в открытую коллекцию и вкладку SFW/NSFW).

Группы: комиксы и вариации. Выдели связанные арты (Ctrl+клик — порядок выделения станет порядком страниц) → «🧩 Сгруппировать» в панели снизу. В галерее группа выглядит одной «стопкой» с бейджем 🧩 N; открытие листает её страницы (стрелки), сбоку — кнопка редактора: имя, тип (комикс/вариации), порядок ↑/↓, исключение лишнего, роспуск группы. ПКМ по стопке — быстрый вход в редактор.

Авто-распределение. ПКМ по арту (или выдели несколько Ctrl-кликом) → «🪄 Авто-распределить»: я сравню теги артов с характерными тегами твоих коллекций и предложу, куда что положить. Ничего не применяется без твоего подтверждения — сначала показываю предложение с галочками. Опционально могу создавать новые коллекции по общему тегу (только если набирается от 3 артов). Работает по тегам, поэтому лучше сначала проиндексировать библиотеку (🧠).

Синонимы и импликации тегов. В ⚙ Настройках → «Связи тегов» можно задать синоним (лис = fox — ищется одно по другому) или импликацию (folf → fox — арты с узким тегом находятся по общему). Разворот применяется к обычному текстовому поиску автоматически.

Из браузера. Установи расширение из папки extension (инструкция в ⚙ Настройках) — и кнопка «🦊 Сохранить в FurryManager» появится в ПКМ на e621, FurAffinity и сотнях других сайтов. Качает арты, гифки и видео с тегами и автором.

С телефона. В ⚙ Настройках включи «Доступ с телефона», перезапусти приложение и отсканируй QR камерой телефона — откроется мобильная страница библиотеки: галерея с поиском и фильтрами, просмотр, кнопка «＋» загружает арты из фотоплёнки прямо в менеджер, «🔗» добавляет по ссылке (ПК скачает через gallery-dl с тегами). «Поделиться → На экран Домой» — и это полноценное приложение. Всё работает по домашней сети с токеном, в интернет ничего не выставляется; ПК должен быть включён. Вне дома — Tailscale/VPN до этого ПК. Для продвинутых: те же POST /ingest и /ingest-file доступны из ярлыков «Команд».

Похожие. «📁 В библиотеке» — дубликаты и почти-копии среди твоих файлов (после индексации — похожие по стилю и содержанию). «🔎 Найти источник» — обратный поиск по FurAffinity, e621, Weasyl, Twitter (через Fluffle.xyz): находит этот же арт на сайтах, автора и первоисточник. «🏷 Похожее по тегам» — открывает на e621/danbooru/FurAffinity поиск по тегам этого арта (можно выбрать какие): так находятся другие арты на ту же тему. Автотеги совпадают со словарём e621/danbooru, поэтому там результат точнее, чем на FA. Найденные «в библиотеке» похожие интерактивны: клик открывает арт, ПКМ — копировать/проводник/в группу/удалить; кнопка «Показать все» внизу открывает похожих прямо в галерее — у поиска появится чип с образцом (клик по нему возвращает к арту, ✕ снимает фильтр).

ИИ (🧠). Кнопка 🧠 справа вверху → «Проиндексировать»: локальная нейросеть просмотрит арты, повесит автотеги (раса, одежда, рейтинг — помечены как авто) и включит умный поиск: жми 🧠 в строке поиска и описывай словами — «рыжий лис в куртке» (лучше по-английски: «red fox in jacket»). Всё работает локально, в интернет арты не отправляются. Первый запуск скачает модели (~1 ГБ). Видео и гифки индексируются по кадру-превью. «♻ Полная переиндексация» стирает автотеги и вектора и проходит библиотеку заново — с опциями авто-SFW/NSFW и раскладки по коллекциям после.

Переустановка и удаление. Библиотека живёт в отдельной папке (её путь — в ⚙ Настройках → Хранение, кнопка «Показать» откроет её в проводнике), а не внутри программы. Поэтому удаление менеджера не удаляет арты: уходят только файлы приложения и ярлыки. Галочка «Удалить данные приложения» в деинсталляторе стирает настройки и ПИН — библиотеку она тоже не трогает. Чтобы вернуться, поставь менеджер заново и укажи ту же папку: теги, коллекции и группы будут на месте. Стереть библиотеку можно только вручную, удалив её папку. Резервная копия — ⚙ Настройки → Хранение → «Экспорт библиотеки» (один zip со всеми файлами и базой).

Избранное и порядок. ★ — быстрая пометка «моё любимое»: правый клик по арту → «★ В избранное» или клавиша F (работает и для выделенных). Чип «★ Избранное» в панели показывает только их. Справа от панели — порядок галереи: новые/старые, крупные/мелкие, «часто смотрю» и случайно (удобно, когда хочется наткнуться на забытое).

Корзина. Удалённые арты по умолчанию попадают в корзину и восстанавливаются вместе с тегами, коллекциями и источником: ⚙ Настройки → Хранение → «Открыть корзину». Там же можно выключить корзину (тогда удаление сразу безвозвратное) и задать, через сколько дней чистить её автоматически — срок считается по дате удаления, так что просроченное подчистится даже после долгого перерыва.

Внешний вид. ⚙ Настройки → Отображение: тема (тёмная / нейтрально-серая / светлая — серая не искажает восприятие цвета), размер миниатюр, «водопад» вместо квадратов (вертикальные арты видно целиком), скрытие подписей и компактный режим.

Режимы интерфейса. «Упрощённый» — только галерея, поиск и коллекции. «Пользователь» — плюс неймспейсы тегов, синтаксис поиска, дубликаты, связи тегов и автопапки. «Художник» — плюс инструменты рисования: 🎨 пипетка, 🪞 зеркало и поворот, ▦ сетка построения (всё в ПКМ по арту в просмотрщике) и два способа держать реф под рукой: 🖼 «Открыть арт поверх окон» — отдельное маленькое окно только с артом (со своим зеркалом, поворотом и прозрачностью; закрывается крестиком окна) и 🔝 в шапке — поверх окон становится весь менеджер (тогда по краю появится оранжевая рамка и подсказка «Выключить»). Режим меняется в ⚙ Настройки → Общие и только скрывает кнопки, данные не затрагивает.

Горячие клавиши: Esc — закрыть, / — в поиск, F — избранное, Ctrl+L — заблокировать шторкой, Ctrl+Shift+A — выделить всё, Ctrl+Shift+H — скрыть NSFW, ← → — листать в просмотрщике, Delete — удалить открытый арт.
