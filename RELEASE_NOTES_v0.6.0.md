# FurryManager v0.6.0

Большое обновление: удаление стало обратимым, появились избранное и сортировка,
настройки внешнего вида, режимы интерфейса под разные типы пользователей,
инструменты для художников — и поддержка Linux.

## 🗑 Корзина — удаление больше не окончательное

Удалённые арты попадают в корзину и восстанавливаются **вместе с тегами,
коллекциями, источником и рейтингом**. Настройки → Хранение → «Открыть корзину».

- Можно выключить корзину — тогда удаление сразу безвозвратное.
- Настраивается срок автоочистки (по умолчанию 30 дней, 0 — не очищать).
  Срок считается по дате удаления, поэтому просроченное подчищается при
  следующем запуске, даже если приложение долго не открывали.

## ★ Избранное и сортировка

- Пометка ★: правый клик по арту, клавиша `F` или звёздочка в просмотрщике.
  Работает и для нескольких выделенных артов.
- Фильтр «★ Избранное» в панели.
- Порядок галереи: новые/старые, сначала крупные/мелкие, «часто смотрю»
  и **случайно** (с кнопкой 🎲 «перемешать заново»).

## 🎨 Настройки отображения

Новая вкладка настроек «Отображение»:

- **Тема**: тёмная, нейтрально-серая (не искажает восприятие цвета — для работы
  с цветом) и светлая.
- **Размер миниатюр** ползунком.
- **«Водопад»** вместо квадратной обрезки — вертикальные арты видно целиком.
- Скрытие подписей на миниатюрах, компактный режим, скрытие полосы прокрутки
  у панели коллекций.

## 👤 Режимы интерфейса

Вместо «Базовый / Продвинутый» — три режима, каждый показывает только нужные
инструменты (данные не затрагиваются, переключается в любой момент):

- **Упрощённый** — галерея, поиск, коллекции, простые теги.
- **Пользователь** — плюс неймспейсы тегов, синтаксис поиска, дубликаты,
  связи тегов, автодобавление из папок.
- **Художник** — плюс инструменты рисования (см. ниже).

## 🖼 Инструменты художника

- **Окно референса**: правый клик по арту → «Открыть арт поверх окон» —
  отдельное маленькое окно только с артом, поверх остальных программ. Внутри:
  зум колесом, панорама, зеркало, поворот, прозрачность, пипетка, «показать в
  проводнике», «копировать», «открыть в менеджере».
- **Весь менеджер поверх окон** (🔝 в шапке) — с рамкой и подсказкой, как выйти.
- В просмотрщике: 🪞 зеркало (проверить композицию), ⟳ поворот, ▦ сетка третей,
  🎨 пипетка.

## 🐧 Поддержка Linux (Ubuntu 22.04+)

Приложение портировано на Linux: `.deb` и AppImage.

```bash
sudo apt install ./FurryManager_0.6.0_amd64.deb
```

Для видео нужны кодеки (вебвью в Linux их не содержит):

```bash
sudo apt install gstreamer1.0-plugins-good gstreamer1.0-plugins-bad \
  gstreamer1.0-plugins-ugly gstreamer1.0-libav ffmpeg
```

Отличия и подробности — в [SETUP.md](SETUP.md).

## 📨 Загрузка из Telegram

Бот-загрузчик: пересылаете ему фото, видео или гиф (в том числе пересланные из
каналов) — они попадают в библиотеку. Настройки → Подключения → «Загрузка из
Telegram» (нужен токен от @BotFather). Ограничение Telegram: файлы больше 20 МБ
бот скачать не может.

## 📱 Офлайн-галерея на телефоне (Tailscale)

Мобильная галерея теперь открывается **без сети** и работает вне дома.
Настройки → Подключения → «Включить доступ через Tailscale»: приложение само
поднимет защищённый адрес, покажет QR — добавьте на экран «Домой» и скачайте
нужные коллекции кнопкой ⤓.

## 🎞 Видео → GIF

Короткие видео можно автоматически превращать в GIF (порог длительности,
кадры/сек, размер и «заменять ли оригинал» настраиваются). Отдельные видео —
через правый клик, без ограничения длины. GIF наследует теги и коллекции
исходного видео.

## 🔒 Приватность

- **Тотальное скрытие NSFW** (`Ctrl+Shift+H`): прячет NSFW-коллекции вместе с
  названиями и блокирует фильтр; при включённом ПИН выключение требует ПИН.
  У каждой коллекции задаётся рейтинг: авто / SFW / NSFW.
- Папки библиотеки скрыты от Проводника и поиска Windows (в Linux — от
  файлового менеджера и галерей), чтобы арты не всплывали в «Недавних».

## ⚙ Прочее

- Очередь задач (справа снизу) с отменой — когда операций больше одной.
- Правый клик работает в «Дубликатах» и «Предложениях групп».
- Приложение больше не показывает белый экран, если библиотека недоступна:
  появляется понятный экран с кнопками «Повторить» и «Указать папку».

  тормоза при воспроизведении.
