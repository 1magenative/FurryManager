# Сборка релиза и установщик

## Linux (Ubuntu)

```bash
bash sidecar/build.sh    # автономный ИИ-модуль (долго, опционально)
bash release.sh          # приложение + .deb и AppImage
```

Готовое — в `src-tauri/target/release/bundle/`. Проверка перед выкладыванием:
установить `.deb` на чистой машине (`sudo apt install ./…deb`), запустить,
убедиться, что открывается библиотека и играет видео (для видео нужны
gstreamer-кодеки, см. SETUP.md).

Собирать Linux-пакеты нужно **на Linux** — кросс-сборка из Windows не
поддерживается. Проще всего: WSL2 с Ubuntu, виртуалка или GitHub Actions
(`ubuntu-latest`).

## Windows

### Быстро

```powershell
cd D:\FurryManager
powershell -ExecutionPolicy Bypass -File release.ps1
```

Готовый установщик: `src-tauri\target\release\bundle\nsis\FurryManager_0.5.0_x64-setup.exe`

Скрипт сам соберёт автономный ИИ-сайдкар (если ещё не собран) и вложит его в
установщик — тогда **пользователю не нужен ни Python, ни консоль**.

Если сайдкар пересобирать не нужно:

```powershell
powershell -ExecutionPolicy Bypass -File release.ps1 -SkipSidecar
```

## Что происходит при установке

- Приложение ставится **для текущего пользователя** (без прав администратора).
- Ярлыки в меню «Пуск» и на рабочем столе создаются автоматически.
- ИИ-сайдкар и `sidecar/main.py` кладутся в ресурсы приложения — оно найдёт их
  само.

## Обновление поверх старой версии

Просто запусти новый установщик. NSIS-установщик Tauri находит уже
установленную версию по идентификатору `app.furrymanager.desktop`, удаляет
старые файлы программы и ставит новые.

**Что сохраняется при обновлении:**

- настройки, ПИН, токен расширения — `%APPDATA%\FurryManager\config.json`;
- вся библиотека (арты, превью, база тегов/коллекций/групп) — она лежит в
  выбранной пользователем папке и установщиком не трогается;
- скачанные ИИ-модели — кэш HuggingFace в профиле пользователя.

То есть после обновления пользователь просто запускает приложение и видит всё
на месте. Версию можно проверить: ⚙ Настройки → Справка → внизу.

## Что происходит при удалении

Удаление (Параметры → Приложения → FurryManager, или `uninstall.exe` из папки
установки) убирает **только саму программу**:

- файлы приложения из `%LOCALAPPDATA%\FurryManager` (exe, ИИ-сайдкар, ресурсы);
- ярлыки и запись в «Установка и удаление программ».

**Библиотека не удаляется никогда.** Она лежит в папке, которую выбрал
пользователь (`store/`, `thumbs/`, `library.db` — арты, превью, теги,
коллекции, группы), вне папки установки и вне `%APPDATA%`. Деинсталлятор туда
не заходит и не может: он даже не знает этот путь.

В окне удаления есть галочка **«Удалить данные приложения»**:

| | галочка снята | галочка стоит |
|---|---|---|
| Библиотека (арты, база) | остаётся | **остаётся** |
| `%APPDATA%\FurryManager\config.json` (путь к библиотеке, ПИН, токен) | остаётся | удаляется |
| Кэш WebView2 (`%LOCALAPPDATA%\app.furrymanager.desktop`) | остаётся | удаляется |
| Кэш ИИ-моделей (~1 ГБ, профиль пользователя) | остаётся | остаётся |

Удаление настроек делает наш хук `src-tauri/windows/hooks.nsh`: штатный
деинсталлятор Tauri чистит только `%APPDATA%\<идентификатор>`, а наш конфиг
лежит в `%APPDATA%\FurryManager`, и без хука ПИН-хэш и путь к библиотеке
пережили бы «удаление данных приложения». При обновлении поверх ($UpdateMode)
хук не срабатывает.

Чтобы вернуться после удаления: поставить приложение заново и указать ту же
папку библиотеки — все теги, коллекции и группы на месте. Кэш моделей тоже
сохраняется, так что заново качать ~1 ГБ не придётся.

Полностью стереть библиотеку можно только вручную, удалив её папку.

## Офлайн-галерея на телефоне (Tailscale)

Чтобы мобильная PWA открывалась **без сети** (и работала вне дома), нужен
доверенный HTTPS — иначе Safari не даёт Service Worker, а без него оболочку
офлайн взять неоткуда. Проще всего это даёт бесплатный Tailscale.

Настройка (один раз):

1. Установи Tailscale на ПК (`tailscale.com/download`) и на iPhone (App Store),
   войди в **один** аккаунт.
2. В менеджере: ⚙ Настройки → Подключения → «Офлайн-галерея на телефоне
   (Tailscale)» → «🔒 Включить доступ через Tailscale». Появятся адрес
   `https://<устройство>.<tailnet>.ts.net/` и QR.
3. Открой адрес на телефоне → «Поделиться → На экран Домой».
4. В галерее скачай нужные коллекции офлайн кнопкой ⤓. После этого приложение
   открывается и показывает арты без сети.

Нюансы:

- Первый `tailscale serve` выпускает TLS-сертификат — если команда ругнётся про
  сертификаты, включи HTTPS в админке Tailscale (DNS → HTTPS Certificates).
- На Windows `tailscale serve` иногда требует прав/оператора: если кнопка вернёт
  ошибку доступа, один раз выполни `tailscale set --operator=<твой_пользователь>`
  (или запусти менеджер от админа).
- Это не требует Perl/NASM/сертификатов в сборке — весь TLS берёт на себя
  Tailscale, менеджер отдаёт обычный http на 127.0.0.1.

## Перед выпуском новой версии

1. Подними версию **в двух местах** (они должны совпадать):
   - `src-tauri/Cargo.toml` → `version = "0.6.0"`
   - `src-tauri/tauri.conf.json` → `"version": "0.6.0"`
2. Обнови `PROJECT.md` (что нового).
3. Собери релиз скриптом выше и проверь установку поверх предыдущей версии.

## Если ИИ-сайдкар не вкладывать

Тогда при первом запуске пользователь нажимает **⚙ Настройки → Хранение →
«⬇ Установить ИИ-компоненты»** (или 🧠 → то же самое) — приложение само
поставит Python-пакеты и скачает модели, с прогрессом в окне. Но Python на
компьютере при этом должен быть. Вариант со вложенным сайдкаром удобнее.

## Известные нюансы

- Первый запуск ИИ качает модели (~1 ГБ) — это нормально и делается один раз.
- Антивирус может насторожиться на свежесобранный PyInstaller-бинарник —
  типичное ложное срабатывание.
- Установщик не подписан: Windows SmartScreen покажет предупреждение
  («Подробнее» → «Выполнить в любом случае»). Убирается только покупкой
  сертификата подписи кода.
