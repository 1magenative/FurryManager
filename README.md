# FurryManager 🦊

Локальный менеджер артов и референсов для Windows: теги вместо папок, коллекции
и группы, умный поиск нейросетью, скачивание из браузера в один клик и доступ
с телефона. **Всё хранится и обрабатывается на вашем компьютере** — без облака,
аккаунтов и аналитики.

## Возможности

**Библиотека**
- Импорт папок и файлов, drag & drop, вставка из буфера обмена
- Дедупликация по содержимому — одинаковые файлы не занимают место дважды
- Режим «без копирования» (in-place) и автодобавление из отслеживаемых папок
- Теги с неймспейсами (`раса:лис`), синонимы и импликации (`folf → fox`)
- Коллекции с авто-распределением; группы: комиксы и вариации одного арта
- Инструмент «Дубликаты»: находит почти-копии и пересейвы
- Экспорт и импорт всей библиотеки одним zip-архивом

**Поиск и ИИ (локально)**
- Поиск по тегам, автору, названию, типу файла
- Умный поиск: описываешь словами — «рыжий лис в куртке»
- Автотеги нейросетью (WD14), включая рейтинг для разделения SFW/NSFW
- «Похожие» в библиотеке по стилю и содержанию; поиск источника в интернете

**Скачивание**
- Браузерное расширение: «Сохранить в FurryManager» на e621, FurAffinity и
  сотнях других сайтов — вместе с тегами и автором
- Поддержка куки браузера для контента, доступного только залогиненным

**Телефон**
- Мобильная веб-галерея (PWA): просмотр со свайпами, поиск, фильтры
- Загрузка артов с телефона в библиотеку и добавление по ссылке
- Офлайн-копия выбранной коллекции в памяти телефона

**Приватность**
- ПИН-код при запуске, шторка при сворачивании и блокировке экрана
- В интернет приложение выходит только по явному действию пользователя

## Установка

Скачайте установщик со страницы [Releases](../../releases) и запустите.
Права администратора не нужны, Python ставить не надо — ИИ-модуль внутри.
При первом запуске приложение спросит, где хранить библиотеку, и проведёт
короткий тур.

Обновление: просто запустите установщик новой версии — настройки и библиотека
сохранятся.

Удаление убирает только программу. **Папка библиотеки не трогается**: арты,
превью и база тегов остаются на месте, и после переустановки достаточно указать
ту же папку. Галочка «Удалить данные приложения» в деинсталляторе стирает
настройки и ПИН — но не библиотеку.

## Сборка из исходников

Нужны: Rust (MSVC-тулчейн), VS Build Tools, WebView2, `cargo install tauri-cli`.
Для сборки ИИ-модуля дополнительно Python 3.11+.

```powershell
cargo tauri dev     # запуск в режиме разработки
```

Установщик одной командой (соберёт и ИИ-модуль):

```powershell
powershell -ExecutionPolicy Bypass -File release.ps1
```

## Структура

```
ui/          — фронтенд (vanilla JS, без сборщика и Node)
src-tauri/   — Rust-бэкенд (Tauri 2, SQLite); pwa/ — мобильная страница
sidecar/     — Python-модуль: CLIP, WD14-теггер, gallery-dl
extension/   — расширение для Chrome (MV3)
```

## Технологии

Tauri 2 + Rust, SQLite, vanilla JS. ИИ: CLIP (ViT-B-32) для семантического
поиска и WD14 (SmilingWolf) для автотегов через onnxruntime — обе модели
работают локально на CPU. Скачивание — gallery-dl.
